# 菜单栏读数和详情面板 — 设计

- 日期：2026-10-29
- 范围：macOS 菜单栏。Windows 这一版不做。
- 草图：`.superpowers/brainstorm/80442-1793257752/content/menubar-v1.html`（不进仓库）。维护者看了草图，回复「可以的」。

## 一、为什么

现在 Cleanzo 在菜单栏里只有一个图标，而且只有打开「后台监控占用增长」时才出现，点开是一个简单菜单。维护者的原话：

- 「菜单栏丰富下吧，现在太简单了，至少显示一些信息，点击也有弹窗可以看详情。做成自己的特色」
- 「只有一个图标，啥信息都没」
- 给了参考图：菜单栏里并排两个读数，上一行小字「CPU」「内存」，下一行「72%」「85%」。
- 「点开看对应项的详情」
- 「这是默认显示的两个状态，其他状态可选择的」

Cleanzo 的特色：别的监控软件只给数字，Cleanzo 的面板还要说清是谁在占、可以做什么。

## 二、目标、非目标

**目标**

- 菜单栏默认显示 CPU、内存两个读数，样式照参考图：上一行小字写名称，下一行写数值。
- 用户可以在「设置」里另外选 GPU、网络、磁盘、温度、电池这几个读数。
- 所有读数画在菜单栏的同一项里，挨在一起、顺序固定；点哪个读数，就打开它自己的详情面板（维护者 2026-10-30 选定，原先是每个读数单独一项）。
- 面板里有一句话诊断，有占用最多的 App，能直接退出 App、打开对应页面。

**非目标**

- Windows 这一版不做，Windows 的任务栏通知区域以后再说。
- 读数的顺序固定，这一版不能在设置里拖动排序。macOS 自带的 ⌘ 拖动可以挪动整组，挪完下次启动还在原处。
- GPU 和网络的面板不列「哪个 App 占得最多」：macOS 没有给普通程序便宜的办法，读不到每个 App 的 GPU 和流量。
- 不存历史，曲线只画面板打开以后的读数，和首页一样。

**做了也算失败**

- 面板关着时，后台读数比第六节的上限更耗电。
- 读不到的项显示成空白、0、「NaN」或者报错，例如 Mac mini 没有电池，读不到温度。
- 用户关不掉，或者找不到怎么退出。

## 三、菜单栏

1. **读数项**：所有读数画在菜单栏的同一项里，从左到右排开，读数之间留一点空。每个读数两行：
   - 上一行是小字名称：CPU、内存、GPU、网络、磁盘、温度、电池；英文界面用 CPU、MEM、GPU、NET、DISK、TEMP、BAT。
   - 下一行是数值：CPU 51%、内存 86%、GPU 14%、磁盘 26.7 GB 可用、温度 43°、电池 100%。
   - 网络不写名称，两行分别是下载和上传：↓156K、↑55K。
   - 内存的数值是已用占总量的比例（首页内存卡的已用 ÷ 总量，如 27.5 / 32 GB 写 86%）。
   - 颜色跟着菜单栏的浅色或深色走。内存紧张时数值变成和首页提示一样的橙色，严重时变红色。
   - 每 2 秒更新一次。数值变化时每个读数占的宽度不跳。
2. **默认**：CPU、内存两项默认打开，其余默认关。
3. **顺序**：读数这一项里从左到右依次是 CPU、内存、GPU、网络、磁盘、温度、电池，没勾选的不出现。勾选变化时这一项原地变宽或变窄，用户用 ⌘ 拖动后的位置保留。合成一项是维护者 2026-10-30 选定的：在真机上，每个读数单独一项时，macOS 26 重新排布菜单栏会把它们挪开、调换顺序。
4. **Cleanzo 图标和菜单**（维护者 2026-10-30：有读数时不再显示 Cleanzo 图标，「这个就不用再显示了」）：
   - 有读数时，菜单栏里只有读数这一项。Cleanzo 的菜单由它给出：右键点读数（或按住 Control 点），或者点面板右下角的「⋯」。
   - 没有读数、只开着后台监控时，菜单栏里是 Cleanzo 图标，点开是同一个菜单。读数这一项和 Cleanzo 图标共用一个位置：一个出现时，就在另一个原来的地方。
   - 菜单的内容：
     - 现有的增长相关几项（近 7 天涨得最多的 App、现在量一次、关闭后台监控）只在打开后台监控时出现；
     - 「打开 Cleanzo」「菜单栏设置…」「退出」，一直都有。
5. **电池**：没有电池的 Mac 上，设置里不出现这一项，菜单栏里也没有。

## 四、详情面板

点菜单栏里的某个读数，在读数这一项下方弹出这个读数的面板；再点同一个读数，或者点面板外面，面板就关上；点另一个读数，换成它的面板。面板打开期间每 2 秒更新。面板底部右边有「⋯」，打开 Cleanzo 的菜单（第三节第 4 条）。

所有面板结构一样，从上到下：

1. 名称和一个大数字，下面一行小字写规格或补充；
2. **一句话诊断**，这是 Cleanzo 的特色，见下表；
3. 一条曲线，画面板打开以后的读数，最多 1 分钟；
4. 这一项的明细；
5. 有「占用最多的 App」的面板列 5 个 App：
   - 每行有 App 图标、名字和数值；
   - 列出的行和「进程」页一样：App、命令行程序、系统进程都算；系统和其他账户的进程是估算值，带「≈」；
   - App 的行悬停时出现「退出」。面板放不下「进程」页的对话框，改成点两下：第一下变成「确认退出」，第二下才退出。退出流程和「进程」页一样，先正常退出，5 秒没退掉，这一行写「还没退出」，旁边出现「强制退出」，同样点两下；
   - 指针在列表里时，列表不重新排序，免得点错；退出还在等待时，面板不自动关上；
   - 点名字，打开 Cleanzo 的「进程」页，并定位到这一行；
6. 底部是打开对应页面的链接。

| 读数 | 一句话诊断 | 曲线 | 明细 | 占用最多的 App | 底部链接 |
|---|---|---|---|---|---|
| CPU | 忙不忙、谁占得最多，如「CPU 很忙：Google Chrome 占得最多（126%）」。说法和「进程」页顶上的诊断一致 | CPU 使用率 | 芯片和核数；负载；性能核、能效核各自的使用率；芯片温度和风扇 | 按 CPU（单核 %） | 打开「进程」页 |
| 内存 | 内存压力、交换文件、谁占得最多，如「内存紧张：系统在压缩内存、写交换文件……Google Chrome 占得最多（5.4 GB）」 | 已用占总量的比例，颜色按内存压力 | 已用和总量；App 内存、联动内存、被压缩、已缓存文件；交换文件 | 按内存 | 打开「进程」页的内存标签 |
| GPU | 忙不忙 | GPU 使用率 | 核数、占用的内存、显示器 | 无 | 打开首页 |
| 网络 | 当前连接是 Wi-Fi 还是以太网 | 下载速度 | 下载、上传速度 | 无 | 打开首页 |
| 磁盘 | 可用空间够不够；增长监控提醒过的 App（如「ToDesk 一天涨了 5.6 GB」） | 读写速度 | 可用和总量；SSD 型号、健康、寿命已用、已写入、温度；读写速度 | 涨得最快的 App（来自增长监控，没打开增长监控时不显示这一块） | 「去清理」打开垃圾清理；「查看」打开「进程」页的磁盘占用标签 |
| 温度 | 散热正常、偏热、很热或过热 | 芯片温度 | 散热状态、芯片温度、风扇、整机功耗、SSD 温度、电池温度 | 无 | 打开首页 |
| 电池 | 正在充电、已充满，或正在用电池 | 电量 | 电量、健康（最大容量）、循环次数、温度、所接电源的功率 | 无 | 打开首页 |

读不到的明细整行省掉，大数字读不到时写「—」，和首页一样。

## 五、设置

「设置」页新增一节「菜单栏」：

- 每个读数一个勾选框，按第三节的顺序排列。没有电池的 Mac 上没有「电池」。
- 全部取消勾选时，菜单栏读数都去掉，Cleanzo 图标回到现在的样子：只在打开后台监控时出现。
- 改动立即生效，并在下次启动时保留。

## 六、数据与开销

- 读数复用首页已有的读法：
  - CPU 和内存同首页；
  - GPU、网络、磁盘读写、温度用首页的机器读数；
  - 磁盘可用空间同首页；
  - 电池电量读 IORegistry 的 `AppleSmartBattery`，不在后台每分钟跑 `system_profiler`。
- **面板关着时**只读勾选了的读数，每 2 秒一次，不读进程列表，不启动子进程。
- **面板打开时**，按需读这个面板要用的数据：CPU 和内存的面板读进程列表，和「进程」页同一套读法；磁盘面板读增长记录。面板关上就停。
- **上限**，量的是 Cleanzo 主进程加子进程：
  - 窗口关着、只有默认两个读数时，不超过一个核的 0.3%；
  - 全部读数打开时，不超过 0.6%；
  - 面板打开时，和「进程」页一样，不超过 3%。网页进程只在面板打开时工作，同样不超过 3%。
  - 面板打开时超出 3%，先去掉其他账户进程那一部分（`ps`），只列本账户的进程。
- **量法**：窗口关着、面板关着，量 60 秒取平均。面板打开的情况，和「进程」页的量法相同。

## 七、窗口和退出

1. 只要有菜单栏读数打开，关掉窗口时 Cleanzo 就留在菜单栏，不退出，和现在打开后台监控时一样。读数全关、后台监控也关时，关掉窗口就退出，和现在一样。
2. 退出 Cleanzo 用菜单里的「退出」（有读数时右键点读数，或点面板里的「⋯」；只开后台监控时点 Cleanzo 图标），或者 ⌘Q。
3. **开机启动**（维护者 2026-10-29 选定）：
   - 「开机时启动」不再依赖后台监控：只要菜单栏有读数，或者后台监控开着，就可以勾。默认仍然不勾。
   - 开机启动时只出现在菜单栏，不弹窗口，和现在后台监控的开机启动一样。
   - 这个开关挪到「设置」的「菜单栏」一节；「占用增长」一节不再放它。
   - 「关闭后台监控」不再连带关掉开机启动，除非菜单栏读数也全关了。读数和后台监控都关时，开机启动自动取消，开关变灰。

## 八、验收

1. 默认安装后，菜单栏有 CPU、内存两个读数：CPU 和首页 CPU 卡的数一致，内存是首页内存卡的已用 ÷ 总量。浅色、深色菜单栏下都看得清；内存紧张时数值变橙色。
2. 七个读数都能在设置里打开、关上，打开后点开各自的面板，内容符合第四节的表；读不到的项不出现空白、0 或错误。用假数据源覆盖：
   - 没有电池；
   - 读不到温度；
   - 没打开增长监控。
3. CPU 和内存面板里的「退出」走「进程」页的流程。点 App 名字打开「进程」页并定位到这个 App。
4. 关掉窗口后 Cleanzo 留在菜单栏；右键点读数、点面板里的「⋯」都能打开菜单，从菜单能重新打开窗口，也能退出。只开后台监控时，Cleanzo 图标的菜单同样可以。
5. 开销达到第六节的上限。
6. Windows 版没有变化。

## 九、留给实现决定

- 两行读数怎么画（文字渲染成图片，还是别的办法），以及在刘海屏 Mac 上读数被刘海挡住时怎么办。
- 面板用系统的弹出框样式（带箭头、半透明底），还是普通浮动面板。
- 面板的宽高，曲线的点数，是否沿用首页的卡片样式。
- 菜单栏设置存在哪个文件里。
- 菜单栏读数和首页同时显示时，是否共用一份采样。

## 十、Claude 替维护者定的（审阅时请重点看）

- **默认打开**：更新后菜单栏自动出现 CPU、内存两个读数，用户可以在设置里关掉。
- **关掉窗口留在菜单栏**：只要有读数打开就留下，读数全关才回到现在的「关窗即退出」。
- **Cleanzo 的菜单**：新增「打开 Cleanzo」「菜单栏设置…」「退出」；增长相关几项只在后台监控打开时出现。有读数时不显示 Cleanzo 图标是维护者 2026-10-30 定的；菜单改从右键点读数、面板里的「⋯」打开，这两个入口是我的决定。
- **可选读数和它们的面板**：GPU、网络、磁盘、温度、电池，各自的面板内容见第四节的表。磁盘面板放 Cleanzo 的特色：涨得最快的 App 和「去清理」。
- **网络读数**不写名称，两行分别是下载和上传。
- **颜色**：只有内存按压力变色。CPU 不变色，因为高 CPU 常常是用户自己在干活，不一定是问题。
- **开销上限**：默认两项 0.3%，全部打开 0.6%，面板打开时 3%。
- **Windows** 这一版不做。
- **开机启动的开关**挪到「菜单栏」一节，读数或后台监控任一开着就能勾（维护者选的是「能勾」，挪位置是我的决定）。
- **面板里的退出点两下**：面板放不下「进程」页的确认对话框。指针在列表里时不重排，退出等待时面板不关。
- **面板列的行**和「进程」页一致，包括系统进程（估算，带「≈」，不能退出）；面板超出开销上限时先去掉其他账户的进程。
- **合成一项的细节**（合成一项是维护者 2026-10-30 选定的）：按点按的位置打开对应读数的面板，面板的箭头指着这一项的中间。读数多时这一项很宽，刘海屏上放不下时 macOS 会把整项藏起来，不再只藏掉其中几个读数。读屏软件按这一项时没有点按位置，打开第一个读数的面板。
- **内存读数**是已用 ÷ 总量，曲线画同一个比例。
