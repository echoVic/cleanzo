# Cleanzo 主要模块动效 · 设计

- 日期：2026-10-22
- 状态：已在 `feat/motion` 分支实现（2026-10-22），浏览器里逐项验收过浅色、深色和减弱动态效果
- 动效稿：`docs/superpowers/specs/2026-10-22-motion-prototype.html`。在浏览器里直接打开。右侧每一条动效都能单独演示，也可以慢放，或模拟「减弱动态效果」。本文和动效稿不一致时，以本文为准。
- 实施计划：`docs/superpowers/plans/2026-10-22-motion.md`

## 一、为什么

现在的界面几乎没有动效，状态之间都是硬切：

- **垃圾清理**：未扫描 → 扫描中 → 结果 → 清理中 → 完成，每一步整块替换。
  - 「可释放空间」的「--」在页面中央，扫描一开始就消失，横幅里冒出另一个数字。
  - 清理中进度条一直是空的，结束时一下填满。
- **数字和条形直接跳**：系统状态每 2 秒刷新一次，大数字、内存条、磁盘条、CPU 曲线都是直接跳到新值。
- **列表增删没有过渡**：
  - 弹窗没有进出场。
  - 分组折叠、行展开、行菜单都是瞬间出现和消失。
  - 移到废纸篓后，行直接消失，下面的行一下顶上来，名次直接换。
  - 测量为空的规则行、已退出的应用行，会突然从列表里消失。
- **减弱动态效果一刀切**：`style.css` 末尾的 `prefers-reduced-motion` 规则把所有动画和过渡压到 0.01ms，说明状态的淡入、对勾也一起没了。

## 二、目标与不做

**目标**

- 覆盖外壳与通用部件、垃圾清理、系统状态、空间分析、大文件、相似照片、应用卸载（含残留页签）。
- 流程、按钮和文案都不变。例外只有第七节列出的几处反馈变化。
- 全应用只有一个招牌时刻：清理完成。其余动效只表达状态、反馈和连贯，常规过渡不超过 240ms。
- 系统打开「减弱动态效果」时，去掉位移和缩放，保留说明状态的淡入淡出和颜色变化。
- macOS（WKWebView）和 Windows（WebView2）表现一致。

**不做**

- 不加依赖（不用 framer-motion 之类），不用 View Transitions API：macOS 12、13 自带的 WebKit 不支持。
- 不做页面加载编排，不加音效。
- 打字搜索不加动画，保证跟手。
- AI 工具、技能、设置三页不单独设计，只继承通用部件：弹窗、展开收起、行收起、复选框。

## 三、动效主线

1. **招牌时刻只有一个：清理完成。**
   - 一道浅绿色的光从左到右擦过横幅。扫到右侧的品牌星标时，星标转 90° 亮一下再暗回去。
   - 已释放的数字同时轻轻落定。
   - 整段约 700ms，只在清理正常结束时播放，条件见 6.2。
2. **同一个东西换了位置就移过去，不消失再出现。** 例如：
   - 「--」从页面中央移到横幅里数字的位置；
   - 排行换名次时，行滑到新位置；
   - 大图从缩略图放大，关闭时缩回原位；
   - 侧栏选中的底色滑到新项。
3. **每个操作 120ms 内有回应，结果说清楚变化。**
   - 按下有反馈，对勾一笔画出。
   - 数字滚动到新值。
   - 行先收起再删除，下面的行补位。
4. **安静。** 循环动画只有忙碌转圈和骨架闪光；新数据进来时只动变化的部分。

## 四、令牌

### 4.1 时长

| 令牌 | 时长 | 用在 |
|---|---|---|
| `--t-press` | 90ms | 按钮按下缩到 97% |
| `--t-fade` | 120ms | 颜色、透明度、文字替换、悬停 |
| `--t-state` | 180ms | 对勾、页面淡入、名次滚动、离场 |
| `--t-layout` | 240ms | 展开收起、行收起、弹窗进场、侧栏底色、页签下划线 |
| `--t-move` | 360ms | 行换位、共享元素移动、大图放大、数据条 |
| 数字滚动 | 420ms | 横幅和指标卡的大数字，中途可以改目标值 |
| 曲线平移 | 450ms | CPU 曲线每次采样左移一格 |
| 清理完成 | 约 700ms | 光带 540ms，290ms 后星标 440ms，全应用只此一处 |

规则：离场比进场快（弹窗关闭 150ms，菜单收起 100ms）。列表里依次进场的项，每项间隔 40ms，最多 6 项有间隔；子项间隔 24ms。

### 4.2 曲线

| 名称 | 值 | 用在 |
|---|---|---|
| 进场 | `cubic-bezier(0.16, 1, 0.3, 1)` | 出现、数字滚动、对勾 |
| 移动 | `cubic-bezier(0.2, 0, 0, 1)` | 换位、展开收起、共享元素、底色和下划线滑动 |
| 离场 | `cubic-bezier(0.3, 0, 0.8, 0.15)` | 消失、关闭 |

不用回弹和弹簧。光带用 `cubic-bezier(0.45, 0, 0.2, 1)`，只此一处。

### 4.3 减弱动态效果

| 动效 | 减弱时 |
|---|---|
| 位移、缩放、换位、共享元素移动 | 不动，直接到位 |
| 展开收起、行收起 | 不做高度过渡，内容 120ms 淡入淡出 |
| 透明度、颜色、高亮圈淡出 | 保留 |
| 数字滚动、曲线平移 | 直接显示新值 |
| 清理完成 | 只保留星标亮一下（透明度） |
| 骨架闪光 | 停止 |
| 忙碌转圈 | 保留，它说明事情还在进行 |

判断依据是 `prefers-reduced-motion: reduce`。mygo 在 macOS 和 Windows 上都会把系统设置映射到这个媒体查询。

### 4.4 性能预算

- 进场、离场、换位只动 `transform` 和 `opacity`。高度只在展开收起和行收起时动，同一时间通常只有一处。
- 换位只处理一次提交里位置变化的前 40 行，更多的直接到位。
- 数字滚动用 `requestAnimationFrame`，只在数值变化时运行。
- 状态页离开或窗口隐藏时停止采样，这一点沿用现有行为。
- 循环动画只有忙碌转圈和骨架闪光，所在视图隐藏（`display: none`）时浏览器自动停止。

## 五、通用部件

新代码放在 `src/ui/motion/`，CSS 放进 `src/style.css`，类名统一加前缀 `cz-`。

| 部件 | 行为 |
|---|---|
| `motion.ts` | `DUR`、`EASE`、`motionLevel()`（`full` / `reduced` / `none`）、`dur()`、`play()`。`none` 表示没有 Web Animations（bun 测试、静态渲染），这时一切直接到位，并且同步完成。 |
| `Collapse` | 外层 grid 行高 0fr ↔ 1fr 过渡，内容淡入淡出。收起动画结束后卸载内容。只在过渡期间裁剪溢出，静止展开时不裁剪，行菜单和焦点环不会被切掉。可选 `animateResize`：展开期间内容变高变矮时也过渡。 |
| `usePresence` + `Leave` | 从列表里消失的项再保留一个离场时长（`leaving`）。期间行收起（高度、内边距归零并淡出），网格项缩小淡出，之后移除。可以按次关闭，例如搜索过滤那次直接移除。 |
| `useFlip` | 子元素按 `data-key` 记位置。key 的顺序变化时，从旧位置滑到新位置。旧位置在渲染阶段读取，中途打断也连贯。 |
| `NumberTicker` | 数字滚动，可以中途改目标值，也可以指定首次从 0 累加。静态渲染输出最终文字，可以渲染成 `<b>`，现有快照不变。 |
| `flyText` / `flyImage` | 共享元素移动：替身从起点飞到终点，期间隐藏终点元素。 |
| `useIndicator` | 页签下划线、分段控件滑块，跟随当前选中项滑动。第一次定位不带过渡。 |
| 弹窗 | 遮罩淡入 180ms；面板淡入，从 97% 放大到 100%，并上移 8px，用 240ms；关闭 150ms。内容换阶段时可以平滑改变高度。 |
| 复选框（Radix） | 先填色，再一笔画出对勾；半选是一条横线从中间展开。垃圾清理页的原生复选框保持原样。 |
| 侧栏 | 选中底色从上一项滑到新项，用 240ms。新视图淡入并上移 4px，用 180ms。没有离场动画，切换不用等。 |
| Toast | 从窗口底部上移 16px 淡入。新消息替换旧消息时只换文字、淡入，不重新弹出。 |

## 六、逐页规格

### 6.1 外壳

- 侧栏底色、视图淡入、弹窗、toast、复选框按第五节实现。
- 侧栏里的 AI 工具、技能入口显隐后，底色立即重新定位，不播动画。

### 6.2 垃圾清理

**状态顺序：** 未扫描 → 扫描中 → 结果 → 清理中 → 完成。

| 时机 | 动效 |
|---|---|
| 开始扫描（从未扫描） | 中央「--」用 `flyText` 移到横幅数字的位置，用 360ms。横幅淡入上移，用 240ms。骨架依次淡入，间隔 30ms。 |
| 规则列表到达（start 事件） | 骨架换成分组列表，分组依次淡入上移，间隔 40ms，最多 6 组。 |
| 每条规则测完（item 事件） | 行内转圈换成大小，淡入 120ms。横幅数字和分组小计滚动累加。 |
| 测量为空的规则 | 行收起后再移除；分组空了，整组收起。 |
| 应用缓存重排 | 按大小排序，测量结果回来后行滑到新位置，用 360ms。 |
| 折叠分组、展开详情 | `Collapse`，箭头同步旋转 90°，用 240ms。 |
| 行菜单 | 从「⋯」按钮处缩放淡入（140ms），点外面或按 Esc 淡出（100ms）。 |
| 停止扫描 | 还没测完的行收起。 |
| 清理中 | 没选的行变淡（180ms）。选中的行依次经过「等待中」、转圈、对勾，对勾一笔画出。横幅数字跟着已清理的字节数滚动，进度条同步前进。 |
| 清理完成 | 招牌时刻，见下。 |
| 重新扫描（从结果或完成） | 横幅留在原地，列表淡出换成骨架。 |

**扫描进度（A 方案）**

- **进度条：** 横幅数字下面展开一根细进度条，按已测量的规则数前进。右侧写「已检查 x / n 项」。开始扫描时后端先发来全部规则（大小为 -1），所以这两个数前端就能算，不用改后端。
- **阶段文案：** 副标题第一段从路径换成阶段文案，取按 `GROUPS` 顺序第一个还有未测完规则的分组，例如「正在扫描浏览器缓存…」。后端 8 条规则并发测量，按这个规则文案只会往前走，不会来回跳。完整路径放在副标题的悬停提示里。
- **走满后收起：** 扫描正常结束时进度条走满，停 450ms 后收起。停止或失败时直接收起。
- **同一根条接着用：** 清理时同一根条从 0 重新展开，改按已清理的字节数 ÷ 计划字节数前进。清理时不显示「已检查」计数。完成后保持现在的宽度规则（`cleanBarWidth`）。

**清理完成（招牌时刻）**

- 横幅加一个 `.hero-sweep` 光带层。光带宽 220px，在 540ms 内从横幅左外侧扫到右外侧，倾斜 14°，两端渐隐。
- 开始 290ms 后，`.hero-spark` 的不透明度从 0.09 升到 0.55 再回到 0.09，同时星标在 440ms 内旋转 90°、放大到 1.16 倍再还原。
- 大数字从 1.06 倍缩回原样，用 420ms。
- **播放条件：** 没有停止、没有失败项、没有出错，且已清理字节数大于 0，也就是进度条走满的那种情况。

### 6.3 系统状态

| 时机 | 动效 |
|---|---|
| 首份读数到达 | 骨架换成读数卡片，只淡入，不位移。 |
| 读数刷新 | 内存、CPU、可用磁盘、电量四个大数字滚动到新值。内存构成条、磁盘条、电池条的宽度过渡 360ms。列表里的数字直接替换。 |
| CPU 曲线 | 新读数从右侧进入，整条曲线 450ms 左移一格，不再整条重画。 |
| 切换排序 | 分段控件滑块滑到新选项（240ms），行按新顺序滑到位置（360ms）。 |
| 采样后重排 | 不冻结时，换了名次的行滑到新位置。鼠标停在列表上、有焦点或确认框打开时冻结顺序，这一点沿用现有逻辑。 |
| 退出应用 | 按钮文字淡入「正在退出…」。成功后整行变淡（现有 300ms）。下一次采样里它消失时，整行收起。 |
| 告警条 | 出现时高度展开、内容淡入；消失时收起，下面的卡片跟着上移。 |
| 查看占内存的应用 | 切到「按内存」，平滑滚到列表（减弱时直接跳），列表标题的高亮圈在 900ms 内淡出。 |

### 6.4 空间分析、大文件、应用残留（共用 `ListRows`）

| 时机 | 动效 |
|---|---|
| 扫描中 | 进度卡展开。新行淡入上移。名次变化的行滑到新位置，名次数字从下方滚入。占用条按新的最大值伸缩，用 360ms。 |
| 展开目录 | 子项区 `Collapse`。读出子项后依次淡入，间隔 24ms，最多 6 项。高度随内容平滑变化。「计算中…」换成大小时淡入。 |
| 移到废纸篓（单个、批量、子项） | 确认后进入现有的忙碌态。完成后，被移走的行收起，下面的行补位，名次滚动更新。空间分析的磁盘卡数字滚动到新值，用量条回落。 |
| 全选、勾选 | Radix 复选框的填色和对勾。 |
| 大文件改下限 | 不达标的行收起，重新达标的行淡入插回原位，其余行滑过去补位。 |
| 停止扫描 | 进度卡收起。 |

### 6.5 相似照片

| 时机 | 动效 |
|---|---|
| 扫描中 | 进度条按处理张数前进；进度卡展开、收起。 |
| 扫描完成 | 照片簇依次淡入上移，间隔 40ms，最多 6 簇。 |
| 打开大图 | 缩略图用 `flyImage` 放大到查看器里图片的实际位置（按 contain 计算），用 360ms。遮罩淡入 180ms，标题栏和底部控件延迟 120ms 后淡入。高清图加载好后替换缩略图。 |
| 上一张、下一张 | 当前图向反方向滑出 16px 并淡出（120ms）；新图从另一侧滑入（200ms，延迟 40ms）。键盘 ← → 一样。 |
| 关闭大图 | 缩略图在可视范围内时，图缩回缩略图（240ms），面板和遮罩淡出。否则面板缩小淡出（150ms）。 |
| 移到废纸篓 | 选中的照片缩小到 0.92 并淡出（180ms），之后同一簇剩下的照片滑到新位置（360ms）。剩不到两张的簇整块收起。 |

### 6.6 应用卸载

| 时机 | 动效 |
|---|---|
| 切换页签 | 下划线滑到新页签（240ms），面板淡入上移（180ms）。 |
| 改排序 | 行按新顺序滑到位置（360ms）。 |
| 搜索 | 即时过滤，不加动画：这次更新既不收起、也不换位。 |
| 卸载详情 | 弹窗先显示「正在分析…」。结果回来后，弹窗高度平滑撑开（240ms），新内容淡入。 |
| 卸载完成 | 这一行收起，下面的行补位，toast 报告移走的大小（现有文案）。 |

## 七、反馈与文案变化

除了动效本身，下面几处和现在不一样，都已在评审中确认：

1. 扫描时，横幅数字下面多一根进度条，写「已检查 x / n 项」。副标题从路径换成阶段文案，完整路径放进悬停提示（6.2）。
2. 清理中，进度条跟着已清理的字节数前进。
3. 行上的「✓」文字换成一笔画出的 SVG 对勾，颜色和大小不变。
4. 「查看占内存的应用」的高亮圈改成淡出（900ms），现在是 1 秒后直接消失。
5. 内存条、磁盘条、占用条改成过渡，现在是直接跳到新值。
6. 测量为空的规则、退出后消失的应用、被移走的行和照片，都先收起再移除。

新增文案（`src/i18n.ts`，中英文）：

| key | 中文 | English |
|---|---|---|
| `scan.progressCount` | 已检查 {done} / {total} 项 | Checked {done} of {total} |
| `scan.phase.system` | 正在扫描系统垃圾… | Scanning system junk… |
| `scan.phase.apps` | 正在扫描应用缓存… | Scanning app caches… |
| `scan.phase.browsers` | 正在扫描浏览器缓存… | Scanning browser caches… |
| `scan.phase.updates` | 正在扫描更新残留… | Scanning update leftovers… |
| `scan.phase.dev` | 正在扫描开发工具缓存… | Scanning developer caches… |
| `scan.phase.review` | 正在查找安装包和备份… | Looking for installers and backups… |
| `scan.phase.custom` | 正在扫描自定义目录… | Scanning custom folders… |

不用「读取浏览器数据」这类说法：Cleanzo 承诺不碰浏览器的历史记录、Cookie 和登录信息。`scan.at` 不再显示，但留在字典里。

## 八、技术约束

- **运行环境：** macOS 12 起的 WKWebView，以及 Windows WebView2。
  - Web Animations、`:scope`、`ResizeObserver`、`color-mix` 都可以用。
  - grid 行高过渡需要 Safari 16 及以上。更老的 WebKit 上会直接展开，不出错。
  - 不用 `@starting-style`；进场一律用挂载时的 CSS 关键帧。
- **测试：** bun 测试没有真实 DOM（`tests/setup-dom.ts` 只提供最小桩），所以：
  - `motionLevel()` 在这种环境下返回 `none`，所有部件直接到位、同步完成，现有断言不用改；
  - 静态渲染（`renderToStaticMarkup`）的输出只能多出包裹层，不能少内容；
  - `shared.ts` 的 toast 必须继续兼容桩元素（只有 `textContent`、`className`、`dataset`、`style`、`addEventListener`）。
- **smoke 截图巡检：** 每次切页后已经等 1 秒，比最长的动效还长，不用改。
- **浏览器验收：** 新增仅开发模式生效的假运行时。`bun run dev:web` 后打开 `http://localhost:5173/?mock`，就能用示例数据驱动真实页面。
  - mygo 原生窗口里 `window.mygo` 已经存在，假运行时不会生效。
  - 生产构建不包含它。

## 九、验证

- **单测：**
