# Cleanzo 0.4.1 Windows 实测计划

日期：2026-11-04（Asia/Shanghai）。目标为公开发布的 0.4.1，远端已安装 0.4.1，安装包及 exe 已与公开发布包核对。

## 当前连接状态

已复用用户打开的内置浏览器云桌面连接（tab 1），Windows 11 Pro 25H2、10.0.26200、64-bit。已完成原 0.2.4 → 0.4.1 升级，安装包和安装 exe 的 SHA256 匹配本地公开发布包；0.4.1 实机用例结果已追加至 report.jsonl，准备阶段旧版本记录单独保留。结束时 Cleanzo 最大化停留系统状态页，恢复 System 外观和 System 语言，测试辅助终端关闭，用户连接保留。

## 用例

| ID | 检查项 | 预期/范围 |
| --- | --- | --- |
| W01 | 环境与构建身份 | 核对 Windows 版本/架构、Cleanzo About 版本、exe 路径、进程与安装来源；目标 0.4.1，未核实构建对应时明确标注。 |
| W02 | 系统状态真实采样 | 观察 CPU、内存、磁盘状态和实时更新，核对 Windows 支持范围内的内容。 |
| W03 | 侧边栏分组与选中态 | 核对概览、清理与空间、AI 工具；逐项切换，检查选中态、内容与 Windows 功能入口。 |
| W04 | 低高度与窄窗口 | 缩小窗口后独立滚动导航，确认底部设置及版本可见，键盘焦点和主要操作可达。 |
| W05 | 图标一致性 | 对照桌面快捷方式、任务栏、窗口和应用内品牌图标；对有缓存或缺失快捷方式的情况单独说明。 |
| W06 | 禁用按钮 hover | 找到真实禁用按钮，记录悬停前后，检查背景、文字与图标不发生错误的悬停样式变化。 |
| W07 | 启用控件与键盘反馈 | 验证启用按钮正常悬停反馈、Tab 焦点以及 Enter/Space 操作，不触发真实删除。 |
| W08 | 深浅主题与保存 | 记录原设置，切换浅色/深色检查文字、描边与控件；正常重开核对选择保存，结束恢复原设置。 |
| W09 | 中英文切换 | 记录原语言，切换中文/English 检查侧栏、设置和长文案，核对原生菜单，结束恢复原语言。 |
| W10 | 垃圾扫描与取消 | 完成只读扫描，核对进度、结果、选择状态；取消扫描后可重试。真实清理需独立授权。 |
| W11 | 空间分析 | 用户目录排行、展开与路径显示，检查测量状态及取消；不移动用户文件。 |
| W12 | 大文件 | 扫描、阈值和选择状态；可用时创建明确 QA 样本做只读检出，记录远端实际字节数。 |
| W13 | 相似照片 | 可用时使用明确 QA 图片验证分组、预览与切换；无夹具时记 partial/not_tested，不删除照片。 |
| W14 | Windows 应用页 | 列表、搜索、筛选、展开、占用与图标；核对不支持的卸载行为，不执行用户应用卸载。 |
| W15 | AI 工具与技能 | 检查 Claude Code、Codex、TRAE 和技能入口，验证只读扫描与无数据状态；不清理真实会话。 |
| W16 | 原生窗口 | 最小化/任务栏恢复、最大化/还原、拖动和标题栏操作；记录窗口和显示缩放。 |
| W17 | 手动检查更新 | 执行检查并观察实际结果，核对最新状态和反馈；若需要安装，准备具体安装包后单独确认。 |
| W18 | 正常重启与结束状态 | 备份核实后的相关设置/数据再正常退出，确认主进程退出并重开，恢复原设置与测试辅助窗口。 |

## 覆盖与操作边界

结果按 pass / fail / partial / not_tested 追加保存，以真实画面与远端读回为证据。安装、升级、卸载、真实删除、系统设置更改及矩阵测试各自记录，不以只读 UI 检查替代。若远端仍是旧版本，先核对旧版本和来源并准备 0.4.1 包；安装或运行新下载软件前遵守电脑操作工具的即时确认要求。

本轮不改产品源码、不提交、不再发布版本。保持单连接、单 UI 操作者，截图和日志不包含会话令牌。
